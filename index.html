Databases in Depth

32 chapters · 28 machines · 165 questions

How a database stores your rows, finds them fast and keeps them through a crash. Then how many machines agree on one answer. In the last part you write a real database in plain Java.

Read chapter 1

  • Foundations and storage engines

    11 chapters

    Data models, how bytes sit on disk, B-trees, LSM-trees and every other index, and how a write survives a crash halfway through.

  • Query engines and analytics

    2 chapters

    How a declarative query becomes a physical plan, and why analytical engines look nothing like transactional ones.

  • Distributed systems

    7 chapters

    Unreliable networks, failure detection, replication, and the algorithms that let separate machines agree at all.

  • Databases in the real world

    6 chapters

    Scaling patterns, reliability and security, cloud-native designs, and a field guide to choosing a database.

  • Build your own database

    6 chapters

    PocketDB in Java: a page cache, slotted pages, a B⁺-tree, a write-ahead log you can kill -9, MVCC, a SQL parser and a server.

Free and open source

HackDynamics is free and open source. The code is under the MIT licence and the course text under CC BY-SA 4.0, so you can read it, translate it, fork it or teach from it. There is no paywall, no card and no sign-up; an account only carries your progress between devices. The site is plain HTML, CSS and JavaScript with no build step. Clone the repository, run python3 -m http.server and the whole thing opens on your own machine. All 239 machines live in the js folder, and every chapter is one JavaScript file you can edit. The most useful thing you can send us is a correction: a wrong fact, a broken machine, a quiz with two right answers. Read the source on GitHub.
